# YSBills-iOS_Local_Bills
# 本地收支记账工具（Python + SQLite）

一款**纯本地运行、不依赖网络与服务器**的个人收支记账小程序。账目保存在脚本同目录的 SQLite 单文件数据库中，从机制上规避“记账 App 下架、云端数据无法导出”导致的数据丢失风险。

> **项目缘起**：家中长辈长期使用的记账 App 下架，云端历史账目未能及时导出，更换手机后多年账目全部丢失。本项目尝试用轻量化的本地程序解决这一真实问题——**数据保存在自己手里，才真正属于自己**。

## 功能特性

| 功能 | 说明 |
|---|---|
| ➕ 添加记录 | 输入收支类型、分类、金额、备注，**自动记录当前时间**（精确到秒） |
| 📋 查看全部 | 按序号展示时间、类型、分类、金额、备注 |
| 📊 收支统计 | 分别汇总总收入、总支出，自动计算结余 |
| 🔍 分类查询 | 按分类（餐饮/交通/学习等）检索账目 |

| 📥 导入 CSV | 支持默认文件或指定路径，兼容新旧格式与多种编码 |
| 🕒 自动时间戳 | 新记录自动写入 `YYYY-MM-DD HH:MM:SS` |
| 🔄 旧库迁移 | 启动时检测旧数据库，自动补充 `created_at` 字段，**旧数据一条不丢** |
| 🛡️ 异常容错 | 编码识别、表头识别、金额清洗、无效行跳过并报告行号 |

## 技术栈

- **Python 3**（标准库，无第三方依赖）
- **SQLite**（`sqlite3`，Python 内置）
- **CSV**（`csv`，Python 内置）
- **datetime**（自动时间戳）

> 因仅使用标准库，**无需 `pip install`**，在纯 Python 环境（含 iOS 上的 a-Shell）中开箱即用。

---

## 环境要求

- Python 3.6 及以上（推荐 3.8+）
- 任意操作系统：Windows / macOS / Linux / iOS（a-Shell）
- 无需网络，无需数据库服务器

**在 iOS 上运行（可选）**：使用 [a-Shell](https://holzschu.github.io/a-Shell_iOS/) 打开终端，将 `bills.py` 放入 `~/Documents`，执行 `python3 bills.py` 即可。数据库与 CSV 会固定生成在脚本同目录。

## 使用说明

### 添加记录（菜单 1）

依次输入：
- **收支类型**：`收入` 或 `支出`
- **分类**：如 `餐饮`、`交通`、`学习`
- **金额**：数字，如 `25.5`
- **备注**：可留空

程序会自动写入当前时间，并回显：

```
✅记录添加完成（时间：2025-01-15 14:32:07）
```

### 查看全部（菜单 2）

```
序号｜时间｜收支类型｜分类｜金额｜备注
1｜2025-01-15 14:32:07｜支出｜餐饮｜25.50｜午饭
2｜2025-01-15 15:01:44｜收入｜零花钱｜100.00｜
```

> 由旧版本升级而来的历史记录，时间列显示为 `-`，不影响其他数据。

### 收支统计（菜单 3）

输出总收入、总支出与当前结余。

### 分类查询（菜单 4）

输入分类名（需与录入时一致，如 `餐饮`），列出该分类下全部账目。

### 删除记录（菜单 5）

先展示全部记录，再输入要删除的**序号**（即 `id`），程序提示删除成功或序号不存在。

### 导出 CSV（菜单 6）

在当前目录生成 `export_bill.csv`，表头为：

```
收支类型,分类,金额,备注,时间
```

### 导入 CSV（菜单 7）

- 直接回车：使用默认文件 `export_bill.csv`
- 或输入其他 CSV 的路径（支持绝对路径；相对路径以脚本目录为基准）

导入完成后会提示成功条数、跳过的无效行数、时间无法识别的条数。

## CSV 导入导出格式

### 列顺序（固定）

| 列 | 字段 | 是否必填 | 说明 |
|---|---|---|---|
| 1 | 收支类型 | 是 | 必须为 `收入` 或 `支出` |
| 2 | 分类 | 是 | 不能为空 |
| 3 | 金额 | 是 | 数字，可带千分位逗号或 `￥/¥/$` 符号 |
| 4 | 备注 | 否 | 可留空 |
| 5 | 时间 | 否 | 缺失或无法识别时使用当前时间 |

### 兼容性说明

- **编码**：优先按 `UTF-8-sig` 读取，失败自动回退 `GBK`（兼容 Excel 另存的 CSV）。
- **表头**：首行同时含“收支类型/type”和“金额/amount”时判定为表头并跳过；无表头也可导入。
- **旧格式**：4 列（无时间）CSV 可正常导入，时间自动补当前时间。
- **支持的日期格式**：
  - `YYYY-MM-DD HH:MM:SS`
  - `YYYY-MM-DD HH:MM`
  - `YYYY/MM/DD HH:MM:SS`
  - `YYYY/MM/DD HH:MM`
  - `YYYY-MM-DD` / `YYYY/MM/DD`

### 示例

```csv
收支类型,分类,金额,备注,时间
支出,餐饮,25.50,午饭,2025-01-15 14:32:07
收入,零花钱,100.00,,2025-01-15 15:01:44
支出,学习,"1,200.00",买书,2025-01-16 09:10:00
```

## 数据存储说明

### 数据库

- 文件名：`account.db`
- 位置：**与 `bills.py` 同目录**（程序以脚本所在目录生成绝对路径）
- 表结构：

```sql
CREATE TABLE bills (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    type       TEXT NOT NULL,      -- 收入 / 支出
    category   TEXT NOT NULL,      -- 分类
    amount     REAL NOT NULL,      -- 金额
    note       TEXT DEFAULT '',    -- 备注
    created_at TEXT                -- 时间 YYYY-MM-DD HH:MM:SS
);
```

### 路径确定性

程序不使用相对路径 `"account.db"`，而是：

```python
BASE_DIR = os.path.dirname(os.path.abspath(__file__))
DB_FILE  = os.path.join(BASE_DIR, "account.db")
```

**为什么这样做？** 在移动端 Jupyter（如 Carnets）等沙盒环境中，相对路径可能被解析到不同临时目录，导致“每次运行都读到一个空库”。固定为脚本同目录后，数据库与 CSV 永远落在同一位置，持久化才有确定性。

### 备份

直接复制 `account.db` 即可完成备份；也可用菜单 6 导出 CSV 作为可读的交换备份。

## 已知限制

1. **控制台界面**：纯文字交互，无图形界面。
2. **明文存储**：`account.db` 未加密，设备被他人获取时可直接查看。
3. **时间不可改**：自动记录时间，但暂不支持手动补录或修改历史时间。
4. **无按时间统计**：`created_at` 目前仅用于展示，尚未实现按时间段汇总。
5. **导入不去重**：重复导入同一 CSV 会产生重复记录。
6. **列顺序固定**：CSV 必须按“收支类型、分类、金额、备注、时间”排列，暂不支持列名映射。

## 常见问题

**Q：运行后提示“暂无记账记录”，但我之前录入过？**  
A：请确认每次运行的是**同一个 `bills.py`**（数据库固定生成在脚本同目录）。若换了目录，会生成新的空数据库。可把旧目录下的 `account.db` 复制过来。

**Q：CSV 用 Excel 打开是乱码？**  
A：本程序导出使用 `UTF-8-sig`，Excel 一般可正常识别。若仍乱码，请在 Excel 中通过“数据 → 从文本/CSV”导入并选择 UTF-8。

**Q：导入时报“金额格式错误”？**  
A：检查该行第 3 列是否为数字。程序会自动去除千分位逗号与 `￥/¥/$`，但不支持“二十五”这类中文数字。

**Q：导入后记录变多了？**  
A：导入功能**不去重**，同一文件导入两次就会翻倍。建议导入前先查看现有账目，或导入到新数据库。

**Q：能在手机上用吗？**  
A：可以。iOS 上使用 a-Shell，把 `bills.py` 放入 `~/Documents` 后执行 `python3 bills.py`。仅依赖标准库，无需安装额外包。
